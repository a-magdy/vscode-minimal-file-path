Minimal File Path

The active file path in your status bar. Diff-aware, click to copy, and zero dependencies.

Install from Marketplace View on GitHub

ext install magdyoss.minimal-file-path
/Users/you/project/src/extension.ts

Mock-up of the status bar in a normal file and in a diff view.

Always visible

The full path of the active file sits in the status bar, with a native VS Code icon.

Diff view support

Uses the modern Tab API to show both paths when you compare two files.

Click to copy

One click copies the path, or both paths in a diff, to the clipboard.

Zero dependencies

Only the native VS Code API and a single small source file. No bloat and no supply chain risk.

Why not just breadcrumbs?

Breadcrumbs and window.title already show the path. This adds an always-visible status bar path, diff view support and click to copy, with no setup required.
